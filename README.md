# HandheldPortraitGodotReady

A Godot starter template for portrait-mode games that feel like playing on a handheld console.

Designed primarily for smartphones and iPhones in portrait orientation, but fully usable on PC.

## Features

- Fixed portrait viewport with proper scaling
- Handheld-style presentation (centered screen + frame)
- Ready-to-use scene structure
- Works on mobile and desktop
- Godot 4.x compatible

## Installation

1. Copy the `addons/HandheldPortraitGodotReady` folder into your project’s `addons/` directory
2. Enable the plugin in **Project → Project Settings → Plugins**
3. Open the provided main scene and start building

## Usage

Replace the content inside the game viewport with your own scenes.  
The template already handles centering, scaling, and the handheld-style layout.
